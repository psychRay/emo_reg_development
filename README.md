# Emotion regulation development analysis reproduction

## Environment

```bash
conda env create -f environment.yml
conda activate er-manuscript
```

Run each figure from the project root. Outputs are written under `outputs/`.
Toy mode generates synthetic participant inputs at runtime; no separate toy
dataset is needed. Atlases and surface templates under `resources/` remain
inputs to spatial mapping. Toy output directories retain only final panel
results after a run. Use the real-data inputs below for participant analyses.

## Figure 1

```bash
python run.py --figure 1 --toy
python run.py --figure 1 --input path/to/fig01_behavior.csv --output outputs/fig01/real
```

## Figure 2

```bash
python run.py --figure 2 --toy
python run.py --figure 2 --input path/to/behavior.csv --profiles path/to/er_profiles.csv --output outputs/fig02/real
```

The separate mediation panel (2f) uses the R scripts under
`analysis/fig02/mediation/`; set their input and output filenames, then run the
scripts with `Rscript`.

## Figure 3

```bash
python run.py --figure 3 --toy
python run.py --figure 3 --input path/to/fig03_design.tsv --fig3-volume-dir path/to/first_level_volumes --fig3-brain-mask path/to/MNI_mask.nii.gz --schaefer-atlas resources/atlases/schaefer2018/Schaefer2018_200Parcels_7Networks_order.dlabel.nii --glm-results-dir path/to/res_glm --output outputs/fig03/real
```

The second command runs panels 3a/3d from participant volumes and a TSV design
matrix, and panels 3b/3c/3e from the GLM result directory. Reference maps and
the Yeo atlas default to `resources/`.

## Figure 6

```bash
python run.py --figure 6 --toy
python run.py --figure 6 --fig6-config analysis/fig06/pipeline/config_paper.json
```

For participant data, set the `paths` values in `config_paper.json`.
Set `matrix_dir` to an `intermediate/` directory under the desired Figure 6
output directory. Existing single-trial LSS betas
can be used with `lss: false`; set `lss: true` to calculate them from BIDS data.
Use `--fig6-steps` to run a comma-separated subset of the original analysis
steps. The toy command starts from small age-ordered neural and behavioral ISC
matrices and exercises the model tests, joint regression, and panels 6b–6d.
Figure 6a is a schematic of the analysis flow.
Toy outputs retain only final results under `fig6b/`, `fig6c/`, and `fig6d/`.
For participant runs, `intermediate/` retains the matrices and statistics.
`fig6c/` contains surface and
volume map data for Connectome Workbench. `fig6d/brain_maps/` contains map data;
the other 6d plots are generated by code.
